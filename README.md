# App Store IPA Creator Web App

GitHub Pages + GitHub Codespaces-ready web app example.

Create an iOS IPA archive information package with a live App Store preview.

## Features

- Enter App Store app information
- Live app information preview
- Generate IPA package information
- Download IPA placeholder package
- Works with GitHub Pages
- Works with GitHub Codespaces
